# Calculater

A lightweight, responsive web-based calculator built with vanilla HTML, CSS, and JavaScript. Deployed on AWS using Amazon S3 Static Website Hosting.

## Live Demo

http://demo-calculator-app-for-cloud-project.s3-website.eu-north-1.amazonaws.com


## Features

- Basic arithmetic operations.
- Responsive and user-friendly interface.
- CSS Grid layout and reusable CSS custom properties.
- Client-side calculations with vanilla JavaScript.
- Lightweight implementation with no external frameworks.

## Tech Stack

- **HTML5** — Application structure.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Calculator logic, event handling, and state management.
- **AWS S3** — Static website hosting.

## Project Structure

```text
simple-cloud-calculator/
├── index.html   # Calculator structure
├── style.css    # Styling and responsive layout
├── script.js    # Calculator logic
└── README.md    # Project documentation
```

## Getting Started

### Prerequisites

- Git
- A modern web browser
- Visual Studio Code (optional)

### Installation

Clone the repository:

```bash
git clone https://github.com/musambokazi/calculater
```

Navigate to the project folder:

```bash
cd calculater
```

### Run Locally

Open `index.html` directly in your browser, or use Visual Studio Code with the Live Server extension for local development.

## Deployment

The application is hosted on **Amazon S3 Static Website Hosting**. The static HTML, CSS, and JavaScript files are served to users through the deployed website URL.
